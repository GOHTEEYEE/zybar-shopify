# Product & Stripe price data

## products.json

Single source of truth for product list and **prices by size** (USD):

- **pricesBySize**: `30x45` and `40x60` amounts in USD (used for display and for creating Stripe Prices).
- **products**: array of `{ slug, name }` (slug must match the product page path, e.g. `audi-r8-white`).

Edit this file when you add products or change prices, then run the sync script.

## Syncing prices to Stripe

1. Put your **Stripe secret key** in `.env`:
   ```bash
   STRIPE_SECRET_KEY=sk_test_xxxxxxxxxxxxxxxx
   ```

2. Run the sync script:
   ```bash
   npm run sync-stripe
   ```

The script will:

- Create or reuse **Stripe Products** (one per product in `products.json`) with `metadata.slug`.
- Create or reuse **Stripe Prices** per product and size (e.g. 30x45 = $110, 40x60 = $150) with `metadata.size`.
- Write **stripe-price-ids.json** with the mapping `prices[slug][size]` → Stripe Price ID.
- Update **js/stripe-config.js** with those Price IDs and `sizePricesUSD` so the site and checkout stay in sync.

3. Set **publishableKey** in `js/stripe-config.js` from your [Stripe Dashboard](https://dashboard.stripe.com/apikeys) (Developers → API keys).

After that, product pages will show the same prices as in `data/products.json`, and checkout will use the corresponding Stripe Price IDs.

## stripe-price-ids.json

Generated by `npm run sync-stripe`. Contains `prices` (slug → size → Price ID) and `sizePricesUSD`. You can commit it or keep it local; the sync script also updates `stripe-config.js` so the frontend has the IDs.
